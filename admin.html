Відкликані коди

Щоб додати учасницю, файл чіпати не треба — коди вже вшиті в бібліотеку й працюють одразу.
Цей блок потрібен лише коли когось видалила або змінила їй код. Тоді відкрий Суспільство_CLUB_бібліотека.html, знайди рядок const BLOCKED = []; і заміни його на цей — старі коди перестануть пускати. Далі перезалий файл на хостинг.

Список зберігається у цьому браузері. Якщо почистиш дані сайту або відкриєш адмінку на іншому комп'ютері — він буде порожній. Тому раз на місяць тисни «Зберегти резервну копію» — файл можна повернути кнопкою «Відновити з копії».
